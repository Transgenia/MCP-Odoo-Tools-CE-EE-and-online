# Support: Odoo Tools Guide

This plugin has no code, so there is nothing to diagnose. If a note about Odoo in it is wrong or out of date, tell Transgenia and it will be corrected. What Transgenia can help with is connecting Claude to your Odoo, training, customization, migration and deployment. Transgenia contracts those services through its official channels (see its Terms of Use: https://github.com/Transgenia/MCP-Odoo-Tools-CE-EE-and-online/blob/main/TERMS-OF-USE.en.md). Free help is limited to the issues of the repository, as its capacity allows, with no service levels.

- Manual: https://docs.transgenia.org/odoo-tools/

## What to send

Send an e-mail or a WhatsApp message with:

- the app you use (Claude Code, Cowork or Claude chat);
- what you want to do with Odoo;
- your Odoo version and edition, if you know them (Community, Enterprise or Odoo Online).

## What never to send

Do not send API keys, passwords, private URLs or customer data, in any channel. Transgenia never asks for them. If you sent an API key by mistake, delete that key in Odoo and create a new one. If you sent a password, change it in Odoo now.

## Security concerns

Do not open a public issue for a security concern about this plugin. Write to dev@transgenia.org

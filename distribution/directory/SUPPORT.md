# Support for Odoo Tools in Cowork

If the plugin loads but a live lookup fails, open Customize > Connectors in the same Claude organization. Check that your intended Odoo connector is connected and available in this task. Run `/odoo-tools:odoo-doctor` to ask it for the server version. Your connector administrator can check expired sign-in, missing read operations or denied access to an Odoo model.

This edition does not start a local server or ask for Odoo settings. The [manual for Odoo Tools](https://docs.transgenia.org/odoo-tools/) also covers the separate local edition for Claude Code.

Contact Transgenia at dev@transgenia.org or WhatsApp +52 55 8034 0405 (https://wa.me/525580340405). Include your Claude surface, the plugin version and a redacted error if available. Do not send API keys, passwords, private URLs or customer data. General issues can be reported on [GitHub](https://github.com/Transgenia/MCP-Odoo-Tools-CE-EE-and-online/issues). Send security reports privately to the support email.

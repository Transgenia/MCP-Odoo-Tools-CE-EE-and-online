Explain that Odoo Tools uses the Odoo connector already authorized for this organization. In Cowork, the user can check Customize > Connectors, connect through the connector's own interface, then run `/odoo-tools:odoo-doctor` to read the server version. If several connections are available, let the user choose the intended one. This help command itself makes no tool calls.

For a live question, the connector determines which reads the user may perform. The bundled version reference is available even without a connection.

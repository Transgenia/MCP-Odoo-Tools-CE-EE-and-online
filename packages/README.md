# Packages

Packages related to odoo-tools. Each folder documents one package.

| Package | What it is | Where it lives |
|---|---|---|
| [`odoo-mcp-tools`](../server/) | The MIT-licensed Python MCP server behind this plugin (import name `odoo_mcp`), published on PyPI. | [`server/`](../server/) in this repository |
| [`odoo-lsp`](odoo-lsp/) | odoo-tools-lsp, a language server for Odoo 10.0-19.0 addons (premium, private preview). | Documentation only: [`odoo-lsp/README.md`](odoo-lsp/README.md). The source is proprietary and is not part of this repository. |

Folders under `packages/` that describe proprietary packages hold a README only, never source code.
The MIT license of this repository covers those READMEs, not the packages they describe.
